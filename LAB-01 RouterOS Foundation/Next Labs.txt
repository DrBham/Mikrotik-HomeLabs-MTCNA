## IMPORTANT LEARNING POINTS

Pada Assessment-01 ditemukan beberapa konsep yang masih perlu diperkuat:

* Interface ≠ IP Address
* `/24` menunjukkan 24 bit network, bukan jumlah host
* ARP Table ≠ Routing Table
* Default Gateway digunakan untuk mencapai network di luar subnet lokal
* `.1` adalah konvensi umum, bukan kewajiban
* Connected route dibuat RouterOS berdasarkan IP/subnet pada interface
* Troubleshooting harus dilakukan secara sistematis
