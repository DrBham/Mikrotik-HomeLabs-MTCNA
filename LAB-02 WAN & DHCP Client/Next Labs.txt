```text
                           PC1

```

**Catatan penting:**

Nomor port/interface di GNS3 **tidak boleh langsung diasumsikan sama** dengan nomor `etherX` di RouterOS.

RouterOS/WinBox digunakan sebagai **source of truth**.

Mapping harus diverifikasi dengan:

```routeros
/interface print
/ip address print
```

# ROUTING

Connected routes:

```text
192.168.10.0/24  → ether2
192.168.56.0/24  → ether1
192.168.100.0/24 → ether3
```

Default route:

```text
0.0.0.0/0 → 192.168.100.1
```

Important understanding:

* `192.168.10.0/24` = LAN network
* `192.168.100.0/24` = WAN network
* `0.0.0.0/0` = default route
* Default route digunakan jika tidak ada route yang lebih spesifik.
* Jangan menyebut `0.0.0.0/0` sebagai "route universal"; istilah teknisnya adalah **default route**.

# TROUBLESHOOTING METHOD YANG HARUS TERUS DILATIH

Gunakan pola:

```text
LINK
 ↓
INTERFACE
 ↓
IP
 ↓
DHCP
 ↓
ROUTE
 ↓
GATEWAY
 ↓
DESTINATION
 ↓
DNS
```

Jangan langsung menebak masalah.

Contoh:

```text
PC1 → Gateway berhasil
        ↓
HQ → WAN Gateway gagal
        ↓
cek ether WAN
        ↓
cek IP WAN
        ↓
cek DHCP Client
        ↓
cek routing
        ↓
ping gateway
```
